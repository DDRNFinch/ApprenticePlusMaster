Apprentice+ V1.5.61 - Evidence Analytics Events

This cumulative release adds meaningful anonymous Firebase event names for:
- Photographic evidence submissions and photo additions
- Learner statement submissions
- Video walkthrough clip saves and completed walkthroughs
- Witness testimony submissions
- Professional discussion recordings and submissions
- Practical assessment submissions
- Supporting evidence submissions and file additions
- Evidence retakes
- Assignment evidence package exports
- Entire portfolio exports
- Portfolio upload confirmations

Only non-personal metadata is sent, such as event type, assignment number, course ID and numeric counts.
No learner names, emails, answers, written evidence, photos, video, audio, signatures or file contents are transmitted.
