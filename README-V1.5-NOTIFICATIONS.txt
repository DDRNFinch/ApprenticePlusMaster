Apprentice+ V1.5 — Notifications Only

This isolated update adds only the first Notification Centre stage:
- Press the Apprentice+ logo to open Notifications.
- Red badge shows unread notification count.
- Notifications can be opened and marked as read.
- A waiting app update appears inside the Notification Centre and still opens the existing update installer.
- No Settings Centre, Learning Support migration, data changes, or course changes are included.
