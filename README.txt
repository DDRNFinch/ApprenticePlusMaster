Apprentice+ v1.3.5 — Recognition of Prior Learning (RPL)

Replace the root project files with the files in this ZIP.

Changes:
- Developer Mode now includes an RPL assignment selector.
- Marking an assignment as RPL instantly completes all four evidence areas.
- RPL assignments display a red diagonal RPL ribbon instead of the green Submitted ribbon.
- The green progress ring counts RPL assignments as submitted completions.
- The yellow progress ring counts an RPL assignment as all four evidence sections completed.
- RPL can be removed from Developer Mode without deleting any existing learner evidence.
- Existing learner records and uploaded assignments are preserved.
- Version and automatic-update cache updated to v1.3.5.

Version 1.3.6 — Academy foundation
- Added permanent Course and Academy bottom navigation.
- Added Academy home with Recommended Revision and Knowledge Library.
- Added a dynamic Knowledge Library generated from the active course assignments and KSB mappings.
- Current and future courses automatically appear without Academy-specific hard-coding.
- Added searchable, expandable revision-topic placeholders ready for teaching content.

Version 1.3.7 — Targeted Revision wording
