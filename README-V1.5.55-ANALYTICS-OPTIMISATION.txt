Apprentice+ V1.5.55 — Analytics Optimisation and Diagnostics

This cumulative release builds on V1.5.54.

Added:
- Dashboard-ready daily engagement summary events.
- Anonymous Firebase user properties for app version, platform and analytics coverage.
- Admin Mode diagnostics showing Firebase connection, queue size and session event totals.
- Controls to send a test event, flush the offline queue, refresh status or clear queued events.
- Larger resilient offline event queue.

Privacy:
No learner names, emails, colleges, employers, evidence text, answers, photos, videos, audio, signatures, files, URLs or location data are included in analytics events.
