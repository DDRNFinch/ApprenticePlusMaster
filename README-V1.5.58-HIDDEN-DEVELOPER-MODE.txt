Apprentice+ V1.5.58 — Hidden Developer Mode

- Removed analytics diagnostics from the existing Admin Mode.
- Tap the app version seven times within 2.2 seconds to open the secret Developer Mode.
- Developer Mode contains Firebase status, analytics queue controls, recent anonymous event names, test tools and privacy information.
- Admin Mode continues to use the existing four-digit code and contains only normal administrative controls.
- Developer Mode closes when dismissed and is not persisted as an unlocked state.
